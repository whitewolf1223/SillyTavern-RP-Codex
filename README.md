# RP Codex — Реестр персонажей для SillyTavern

Версия: **0.1.0 (первая тестовая)**.

## Возможности

- Отдельная сворачиваемая панель **NPC**, которая не вставляет списки в сообщения модели.
- Индивидуальный реестр для каждого чата (хранение в `chatMetadata` SillyTavern).
- Карточки NPC: имя, группа, роль, статус, характер, отношения, заметки.
- Статусы: жив / мёртв / пропал / неизвестно. Имена умерших зачёркиваются.
- Ручное редактирование и поиск, фильтрация по группам.
- Экспорт и импорт JSON.
- Шаблон из 24 трибутов для AU «Голодные игры» с Анн Уитмор в Дистрикте 12.
- Кнопка **«Анализировать сообщения»**: модель просматривает выбранное количество последних сообщений и предлагает добавить или обновить персонажей. Изменения применяются только после подтверждения.

## Установка через GitHub

В SillyTavern открой **Extensions → Install Extension** и вставь:

```text
https://github.com/whitewolf1223/SillyTavern-RP-Codex
```

Установи расширение, затем обнови страницу SillyTavern. Должна появиться кнопка **NPC** в нижней правой части экрана.

Для обновлений используй менеджер расширений SillyTavern.

## Использование

1. Открой ролевой чат.
2. Нажми кнопку **NPC**.
3. Добавляй персонажей вручную или запусти анализ сообщений.
4. Для «Голодных игр» открой «Инструменты и резервная копия» и выбери шаблон **24 трибута**.
5. Проверь предложения модели и нажми «Принять отмеченные».
6. Перед удалением чата сохрани JSON через «Экспорт».

## Ограничения

- Это **тестовая версия**; в работающем экземпляре SillyTavern пока не проверена.
- Анализ запускается **вручную**, а не после каждого ответа.
- Анализ использует текущую модель/API SillyTavern и может расходовать платные токены.
- Характеры и отношения сохраняются текстом; интерактивного графа пока нет.
- Данные реестра **не передаются модели автоматически** при обычном ответе.
- Модель может неверно извлечь факты или статус. Проверяй предложения до сохранения.
- Реестр привязан к чату. Сделай экспорт перед удалением чата.
